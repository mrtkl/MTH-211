Chapter 3 overview

Chapter 3Topics Addition and Subtraction · Multiplication and Division · Ordering and Exponents

Big idea. Each operation is defined from what we already know: addition from the union of disjoint sets, subtraction from addition (missing addend), multiplication from addition (repeated addition), and division from multiplication (missing factor). For each operation, future teachers need three things: the conceptual approaches children use, the models (set and measurement) that show them, and the properties that make the basic facts and mental math work.

Approach vs. model. An approach is the way of thinking about the operation (take-away, missing addend, sharing, …). A model is the picture used to show it (a set of objects or a number line). Every problem is solved with one of each.

Figures and worked examples. Items marked New add figures, worked examples and classification tasks that parallel the chapter (with new numbers and contexts).

How to use this file. The notes pages explain the content with manipulatives you can project. Each activity page lists the handout’s questions in order with buttons that open the matching tool, already set up. Instructor notes are in the teal “Teaching notes” boxes.

Chapter 3 Notes (1): Addition of Whole Numbers

Leads to Activity 3.2

1. Set model for addition

Definition. Let a and b be whole numbers. If A and B are disjoint sets with n(A) = a and n(B) = b, then the sum of a and b is a + b = n(A ∪ B).
Example. A = {♠, ♥, ♦} and B = {★, ●}. These sets are disjoint and A ∪ B = {♠, ♥, ♦, ★, ●}, so 3 + 2 = n(A ∪ B) = 5.

In the equation a + b = c, a and b are the addends and c is the sum.

Why disjoint? If the sets share elements, the union counts each shared element only once, so n(A ∪ B) would be less than a + b. Try it below.

When the sets are not disjoint New

If A and B share elements, the shared elements are counted twice in n(A) + n(B), so we subtract them once:

n(A) + n(B) − n(A ∩ B) = n(A ∪ B)

Worked example. Use the definition of addition to compute 3 + 6.
Choose disjoint sets: A = {m, n, o} and B = {p, q, r, s, t, u}. Then n(A) = 3, n(B) = 6 and A ∩ B = ∅, so
3 + 6 = n(A ∪ B) = n({m, n, o, p, q, r, s, t, u}) = 9.

Addition is a binary operation: it combines two numbers to produce one unique number. Union, intersection and set difference are binary operations on sets.

2. Measurement model for addition

On the whole-number line, a is an arrow of length a starting at 0, and b is an arrow of length b placed at the end of the first. The sum is where the second arrow ends. To model 3 + 5: an arrow from 0 to 3, then an arrow of length 5 from 3 to 8.

Notice that the arrows are placed end to end and do not overlap, just as the sets in the set model are disjoint.

3. Properties of addition

  • Closure: the sum of any two whole numbers is a whole number. We say “the set of whole numbers is closed under addition.”
  • Commutative: for all whole numbers a and b, a + b = b + a.
  • Associative: for all whole numbers a, b and c, (a + b) + c = a + (b + c).
  • Identity: there is a unique whole number, 0, such that a + 0 = 0 + a = a for every whole number a. Zero is the additive identity: adding it preserves the identity of the number.

Use the number line above: choose a property to see why it is true for every choice of numbers, not just one example.

Closure in action New. The even numbers {0, 2, 4, …} are closed under addition (even + even is even), so a column of even numbers that adds to an odd total signals an error. The odd numbers {1, 3, 5, …} are not closed: 3 + 5 = 8 is even.

Properties at work. A child who knows the facts up to 5 + 5 can find 7 + 2 as 5 + 4 by moving one: 7 + 2 = (6 + 1) + 2 = 6 + (1 + 2) = 6 + 3, and so on down to a known fact. Commutativity lets a child count on from the larger addend: 2 + 9 is found as 9, “10, 11.”

Teaching notes: Notes (1)
  • The overlap demonstration is the reason the definition says disjoint. Ask: “If 3 children have a dog and 4 have a cat, are there 7 children with pets?”
  • On the number line, insist that arrows start where the previous one ends. Students often draw both arrows from 0.
  • Closure is easy to state for addition and becomes interesting for subtraction and division (Activity 3.7).
  • Run the fact-table stepper on the projector and ask students to predict each count before clicking (55, 45, 28, 25, 19). The point: children learn strategies, not 100 isolated facts.
  • The base seven and base nine sums put students in a child’s position: they cannot recall the fact, so they must make the base.

Chapter 3 Notes (2): Subtraction of Whole Numbers

Leads to Activity 3.3

In the subtraction equation a − b = c, a is the minuend, b is the subtrahend, and c is the difference.

1. The take-away approach

Definition (set model). Let a and b be whole numbers and A and B be sets with n(A) = a, n(B) = b and B ⊆ A. Then a − b = n(A − B).
  • Set model example: Jill has 9 marbles and gives away 5. Show 9 counters, remove 5, and 4 remain: 9 − 5 = 4.
  • Measurement model example: on the number line, draw an arrow from 0 to 9, then an arrow of length 5 pointing back from 9. It ends at 4.
Take-away with a measurement model New. Kai hikes 8 km from camp, then turns and walks 3 km back toward camp. How far from camp is he? 8 − 3 = 5.

2. The missing-addend approach

Definition. Let a and b be whole numbers. Then a − b = c if and only if a = b + c for some whole number c. c is called the missing addend.

The missing-addend definition shows the relationship between addition and subtraction: every subtraction is an addition with one addend unknown.

  • Set model example: Ron has 5 stickers and needs 9 for a page. How many more? Start with 5 counters and add counters until there are 9: he adds 4, so 5 + 4 = 9 and 9 − 5 = 4.
  • Measurement model example: draw an arrow from 0 to 5; how long an arrow reaches 9? Jump from 5 to 9: the jump has length 4.
Making change is missing addend New. A snack costs 58¢ and you pay with $1. A clerk counts up from the price instead of subtracting: “58 … 60, 70, 80, 90, a dollar,” handing back 2 pennies and 4 dimes. The change is the missing addend: 58 + 42 = 100, so 100 − 58 = 42.

Missing addend also explains why subtraction is not closed: no whole number c makes 4 = 6 + c, so 4 − 6 has no whole-number answer.

3. Four-fact families

Because of the commutative property and the missing-addend relationship, 5 + 4 = 9 belongs to a family of four facts: 5 + 4 = 9, 4 + 5 = 9, 9 − 4 = 5 and 9 − 5 = 4.

4. The comparison approach

In some problems another step must come first. Cory has 9 cards and Hasni has 5. How many more cards does Cory have? We first match the two sets one to one (comparison), then find how many are left over, either by taking away the matched ones or by asking what must be added to 5 to get 9.

This is the comparison approach together with the take-away or missing-addend approach. The comparison approach is not enough alone; it is always followed by one of the other approaches.

Classifying subtraction problems New

Two approaches (take-away, missing addend) times two models (set, measurement) give four kinds of problems. Here is one story for each:

Approach vs. model. When solving a problem, you choose both an approach (take-away, missing addend, comparison) and a model (set or measurement) that illustrates that approach.

Explore the approaches

Choose an approach and a model, set the numbers, and build the picture step by step.

Teaching notes: Notes (2)
  • Take-away needs B ⊆ A: you can only take away objects that are there. That is why subtraction is not closed on the whole numbers (Activity 3.7).
  • Missing addend is how most adults actually compute 13 − 8 (“8 and 5 more is 13”). Make that explicit; it is the bridge to the missing-factor approach for division.
  • Comparison problems are the hardest for children because nothing is taken away and nothing is added: two sets are compared.
  • Use the cube to have students write their own story for an empty cell, then trade and classify.

Chapter 3 Notes (3): Multiplication of Whole Numbers

Leads to Activity 3.4

In the equation a × b = c, a and b are the factors and c is the product.

Three approaches to multiplication

1. Repeated addition. Let a and b be whole numbers. Then a × b = b + b + … + b (b added to itself a times). This depends on the relationship between addition and multiplication. (Also, 1 × b = b and 0 × b = 0.)
  • Set model example: 3 bags with 4 apples in each: 4 + 4 + 4 = 3 × 4 = 12.
  • Measurement model example: 3 jumps of length 4 on the number line, end to end, land on 12.
2. Rectangular array. Let a and b be whole numbers. Then a × b is the number of objects in an array with a rows and b columns (an a by b rectangle).
3. Cartesian product. Recall that S × T is the set of all ordered pairs (s, t) with s ∈ S and t ∈ T. If n(A) = a and n(B) = b, then a × b = n(A × B).
Example. 3 shirts and 2 pairs of pants make 3 × 2 = 6 outfits, one for each ordered pair (shirt, pants). A tree diagram lists them.
Cartesian product, listed and as an array New. Sandwiches S = {turkey, cheese}, drinks D = {milk, juice, water}. Each lunch is an ordered pair (sandwich, drink), so 2 × 3 = n(S × D) = 6. Arranging the pairs in rows and columns shows the Cartesian product is an array.

Properties of multiplication

  1. Closure: the set of whole numbers is closed under multiplication, since the product of any two whole numbers is a whole number.
  2. Commutative: for any whole numbers a and b, a × b = b × a.
  3. Associative: for any whole numbers a, b and c, (a × b) × c = a × (b × c).
  4. Identity: the number 1 is the multiplicative identity since, for any whole number a, a × 1 = 1 × a = a.
  5. Distributive property of multiplication over addition (subtraction): for any whole numbers a, b and c, a × (b + c) = a × b + a × c and a × (b − c) = a × b − a × c (when b ≥ c).
  6. Multiplication property of zero: for every whole number a, a × 0 = 0 × a = 0.

Closure, two quick checks New. The odd numbers are closed under multiplication (odd × odd is odd), so an even product of odd factors means an arithmetic slip. The set {2, 6, 10, 14, …} is not closed: 2 × 6 = 12 is not in it.

Commutativity saves work. By repeated addition, 8 × 2 is 2 + 2 + … + 2 (eight 2s), but 2 × 8 = 8 + 8 is a double the child already knows.

c. xy + xz = x(y + z)    d. 43 × 25 + 57 × 25 = (43 + 57) × 25 = 2500
e. a(b + c + d) = a((b + c) + d) = a(b + c) + ad = ab + ac + ad

Teaching notes: Notes (3)
  • In this course, a × b means “a groups of b.” The commutative property says the products are equal, not that the pictures are the same (Activity 3.4, Part 1).
  • The Cartesian product is the approach children find least natural; it is also the one that makes 0 × b = 0 obvious (no shirts, no outfits).
  • The distributive property is behind every multiplication algorithm (Chapter 4).
  • The ×9 patterns (tens digit one less than the multiplier; digits add to 9) are worth having students explain, not just notice: 9 × n = 10n − n.

Chapter 3 Notes (4): Whole-Number Division

Leads to Activity 3.5

In the expression a ÷ b = c, a is the dividend, b is the divisor, and c is the quotient. Division of whole numbers can be interpreted conceptually in two different ways:

1. Sharing (partitive) division. There are r objects to be divided (shared, or partitioned) into s groups. The answer to r ÷ s is the number of objects in each group.
2. Measurement (subtractive, grouping) division. There are r objects to be divided (measured out) into groups with s objects each. The answer is the number of groups you form.

Sharing or measurement? New

Ask: do I know the number of groups (sharing: find the size of each group) or the size of each group (measurement: find the number of groups)? The difference matters more later with fractions and decimals.

  • A bus travels 60 miles each hour. How long to go 180 miles? Measurement: how many 60s are in 180.
  • Six friends split 48 stickers equally. How many each? Sharing: 6 groups, find the group size.
  • 72 eggs go into cartons of 12. How many cartons? Measurement.

Other notation: a ÷ b can also be written a/b, as a fraction with a over b, or with the long-division bracket, b written outside and a inside.

Division related to the other operations

1. Missing-factor approach (relates division to multiplication). If a and b are whole numbers and b ≠ 0, then a ÷ b = c if and only if c is the whole number with b × c = a.
Example. To model 28 ÷ 7, use 28 units to form a rectangle with one side of length 7. The answer is the missing side of the rectangle: the number that, when multiplied by 7, makes 28. It is 4.
Worked example. Find each quotient with the missing-factor approach. New
36 ÷ 9 = 4 since 36 = 9 × 4  ·  63 ÷ 7 = 9 since 63 = 7 × 9  ·  56 ÷ 4 = 14 since 56 = 4 × 14  ·  0 ÷ 8 = 0 since 0 = 8 × 0
The multiplication table doubles as a division table: find 7 in the row label, then 63 in that row; the column label is the quotient.
2. Repeated-subtraction approach (relates division to subtraction). a ÷ b is the number of times b can be subtracted from a until 0 is reached.
Example. 15 ÷ 5: 15 − 5 = 10, 10 − 5 = 5, 5 − 5 = 0. We subtracted 5 three times, so 15 ÷ 5 = 3.

Explore the approaches

Division involving 0, and the division algorithm

  • If a is any nonzero number, then 0 ÷ a = 0, because a × 0 = 0.
  • a ÷ 0 is undefined for all whole numbers a. If a ≠ 0, no c makes 0 × c = a. If a = 0, every c makes 0 × c = 0, so there is no unique answer.
The division algorithm. If a and b are whole numbers and b ≠ 0, then there exist unique whole numbers q (quotient) and r (remainder) such that a = bq + r with 0 ≤ r < b.

Examples: 23 = 5 · 4 + 3, so 23 ÷ 5 has q = 4 and r = 3. And 4 = 5 · 0 + 4, so 4 ÷ 5 has q = 0 and r = 4.

Why remainders matter New. 29 crayons are shared equally by 4 children. 29 = 4 × 7 + 1, so each child gets 7 crayons and 1 is left over. The quotient answers “how many each,” the remainder answers “how many left.”
Worked example. Find the quotient and remainder.
a. 61 ÷ 7: 7 × 8 = 56, so 61 = 7 × 8 + 5  (q = 8, r = 5)
b. 50 ÷ 12: 12 × 4 = 48, so 50 = 12 × 4 + 2  (q = 4, r = 2)
c. 84 ÷ 7: 7 × 12 = 84, so 84 = 7 × 12 + 0  (q = 12, r = 0)
Teaching notes: Notes (4)
  • The two tennis-ball problems both give 24 ÷ 3 = 8, but a child acts them out completely differently: dealing out balls (sharing) versus making groups of 3 (measurement). Ask students to act them out with counters.
  • For 0 ÷ 0, students often say 0 or 1. Use the missing-factor check: 0 × c = 0 works for every c, so no single answer can be chosen.
  • The remainder must be less than the divisor; otherwise another group could still be formed.
  • The scaffold method is the bridge to long division in Chapter 4: students who take small chunks still get the right answer, only more slowly.

Chapter 3 Notes (5): Ordering Whole Numbers and Exponents

Leads to Activity 3.7

We have already seen three methods for ordering whole numbers: the counting chant, matching elements of sets (the set method), and the number line. Now that we have whole-number operations, there is a new formal definition:

Definition (less than for whole numbers). a is less than b, written a < b, if and only if there is a nonzero whole number n such that a + n = b.

Examples: 3 < 8 because 3 + 5 = 8. And 0 < 4 because 0 + 4 = 4. But 6 is not less than 6: the only n with 6 + n = 6 is n = 0, which is not allowed.

See the definition on a number line

A proof of the transitive property New
a < b means a + n = b, n ≠ 0definition of less than b < c means b + m = c, m ≠ 0definition of less than a + n + m = b + m = cadd m to both sides, substitute a + (n + m) = c, with n + m ≠ 0so a < c

Properties of less than and whole-number operations

  1. Transitive: for all whole numbers a, b and c, if a < b and b < c, then a < c. Example: 2 < 5 and 5 < 9, so 2 < 9. (2 + 3 = 5 and 5 + 4 = 9, so 2 + 7 = 9.)
  2. Less than and addition: if a < b, then a + c < b + c. Example: 3 < 7, so 3 + 10 < 7 + 10, that is, 13 < 17.
  3. Less than and multiplication: if a < b and c ≠ 0, then a × c < b × c. Example: 3 < 7, so 3 × 4 < 7 × 4, that is, 12 < 28. (With c = 0 both products are 0, so the inequality fails.)

Exponents New

Multiplication shortens repeated addition; exponents shorten repeated multiplication.

Definition (whole-number exponent). For whole numbers a and m with m ≠ 0, am = a × a × … × a (m factors). a is the base and m is the exponent (power).

Examples: 42 = 4 × 4 = 16 (“4 squared”), 33 = 3 × 3 × 3 = 27 (“3 cubed”), 25 = 2 × 2 × 2 × 2 × 2 = 32.

Count the factors. Writing out the factors is the whole proof of each rule.
52 × 54 = (5·5)(5·5·5·5) = 56am · an = am+n 23 × 73 = (2·2·2)(7·7·7) = (2·7)(2·7)(2·7) = 143am · bm = (ab)m (32)3 = 32 · 32 · 32 = 36(am)n = amn 67 ÷ 64 = 63, since 67 = 64 × 63am ÷ an = am−n (m > n)
No rule for sums. (2 + 3)2 = 25 but 22 + 32 = 13. Exponents distribute over multiplication, not over addition.

Why a0 = 1. The definition needs m ≠ 0, so we choose a meaning that keeps the pattern: each step down divides by 2.

Teaching notes: Notes (5)
  • Connect the definition to the missing-addend approach: a < b exactly when b − a is a nonzero whole number.
  • Each property has a number-line picture: transitive (jumps add up), addition (slide both points by c), multiplication (stretch the line by c).
  • Exponents: ask students to justify each rule by writing out factors before stating it. Expect (a + b)2 = a2 + b2; the 2 + 3 example settles it.

Activity 3.4: Understanding Properties of Multiplication

Notes Notes (3)Manipulative crayons, arrays, cubes, quilt squares

Part 1: The commutative property. Sandy has 4 identical boxes of 8 different colored crayons.

  1. Draw a picture of the situation.
  2. Explain how the picture shows 4 × 8 (four groups of eight). What are you counting 4 of? 8 of?
  3. Sandy dumps the crayons and sorts them to show 8 × 4. What are you counting 8 of? 4 of?
  4. Write a word problem you would naturally write as 3 × 5, draw a model and explain why.
  5. Write a word problem you would naturally write as 5 × 3, draw a model and explain why.

Part 2: The associative and distributive properties.

  1. 4 × (25 × 17): what is done first by the order of operations?
  2. How does the associative property make it easier? Find the product.
  3. 4 × (25 + 8): what is done first?
  4. How does the distributive property make it easier? Find the product.
  5. 21 × 12: use the distributive property.

Part 3: Models of the distributive property. Ms. Garity’s class made 3 rows of 5 quilt squares; Ms. Gold’s made 4 rows of 5. How many squares in all?

  1. Ary’s way: 5 times the total number of rows. Draw pictures and write the number sentence.
  2. Gabriella’s way: find each class’s total, then add. Draw pictures and write the number sentence.
  3. Explain how their work illustrates the distributive property of multiplication over addition.
Teaching notes: Activity 3.4
  • Part 1: in 4 × 8 we count 4 boxes with 8 crayons in each; in 8 × 4 we count 8 colors with 4 crayons of each color.
  • Part 2: parentheses first gives 25 × 17 = 425, then × 4. Associative: (4 × 25) × 17 = 100 × 17 = 1700. Distributive: 4 × 25 + 4 × 8 = 100 + 32 = 132. 21 × 12 = (20 + 1) × 12 = 240 + 12 = 252.
  • Part 3: Ary: (3 + 4) × 5 = 7 × 5 = 35. Gabriella: 3 × 5 + 4 × 5 = 15 + 20 = 35. Both are equal, which is (a + b) × c = a × c + b × c.

Activity 3.5: Understanding and Modelling Approaches to Division

Notes Notes (4)Manipulative counters, gift bags, number line

Part 1: Measurement and sharing division. Arya has 24 candies to put in equal amounts into gift bags.

  1. 4 candies in each bag. How many bags?
  2. 3 candies in each bag. How many bags?
  3. 5 candies in each bag. How many bags?
  4. 4 gift bags. How many candies in each?
  5. 3 gift bags. How many candies in each?
  6. Write a number sentence for #1, 2, 4 and 5.
  7. Write two word problems answering “What is 27 ÷ 3?”: one most naturally measurement, one most naturally sharing.
  8. Jordan’s crew has an 18-mile stretch; he stops every 3 miles. How many stops? Use a number line.
  9. How does the measurement approach show the relationship between division and subtraction?

Part 2: The missing-factor approach. 1) 15 ÷ 3 and 18 ÷ 6 as missing-factor problems. 2) Explain 0 ÷ 15 and 15 ÷ 0.

Part 3: Quotient and remainder. 1) 23 ÷ 5, 15 ÷ 5, 4 ÷ 5. 2) Tina’s 43 oranges, 8 per box. 3) Four word problems for 25 ÷ 6 with answers 4; 5; quotient 4 remainder 1; 4 1/6.

Teaching notes: Activity 3.5
  • Answers: #1 6 bags; #2 8 bags; #3 4 bags with 4 candies left; #4 6 candies; #5 8 candies. #8: 6 stops (18 → 15 → 12 → 9 → 6 → 3 → 0).
  • Part 2: 15 ÷ 3 = 5 since 5 × 3 = 15; 18 ÷ 6 = 3 since 3 × 6 = 18; 0 ÷ 15 = 0 since 0 × 15 = 0; 15 ÷ 0 is undefined since no c gives c × 0 = 15.
  • Part 3: 23 ÷ 5 → q 4, r 3; 15 ÷ 5 → q 3, r 0; 4 ÷ 5 → q 0, r 4. Tina: (a) smallest 6 boxes, largest 43; (b) 5 boxes; (c) 3 left over; (d) 5 more oranges and 1 more box.

Activity 3.7: Exploring the Closure Property

Notes Notes (1), (3), (5)Manipulative closure tester
Closure. A set A is closed under addition if whenever a ∈ A and b ∈ A, we know that a + b ∈ A. Likewise A is closed under multiplication (a × b ∈ A), subtraction (a − b ∈ A) or division (a ÷ b ∈ A) when the result is always in A. Note: a and b may be the same number.
  • Not closed: one counterexample is enough. “This set is not closed under addition because 1 and 2 are in the set and 1 + 2 = 3, but 3 is not in the set.”
  • Closed, infinite set: give a general argument: write two elements in general form (for example 2m and 2n), apply the operation, and show the result has the same form.
  • Closed, finite set: list every result and check that each one is in the set.

The tester below searches for a counterexample among small elements and shows the general argument when the set is closed. Decide first, then test.

Teaching notes: Activity 3.7
  • #1 addition: closed for a, b, g, h; not closed for c (1 + 1), d (1 + 1), e (1 + 2), f (1 + 1), i (1 + 2 = 3).
  • #2 subtraction: only {0} is closed. All others contain a pair with a smaller first number or, for i, 4 − 1 = 3.
  • #3 multiplication: closed for a, b, c, d, f, g, and h (3 can only be made as 1 × 3, and 3 is not in the set); not closed for e (2 × 2) and i (2 × 3 = 6).
  • #4 division: only {1}. Sets containing 0 fail because division by 0 is undefined; others fail by examples such as 2 ÷ 4.
  • #5: 10, 15, 20, … (all positive multiples of 5). #6: 25, 125, 625, … (all powers of 5). #7: negative integers. #8: fractions (positive rational numbers).

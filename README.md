# MTH 211: Foundations of Elementary Mathematics

Interactive course pages for **MTH 211** at Oregon State University, Department of Mathematics.

**Start here: [https://mrtkl.github.io/MTH-211/](https://mrtkl.github.io/MTH-211/)**

Each chapter is a single web page that runs in any browser, with no login or installation. Every chapter includes:

- **Notes** with short explanations and worked examples
- **Activities** from the MTH 211 activity packets, in a suggested order, with buttons that open a virtual manipulative set up for each problem
- **Self-Study Quiz** with answers and detailed solutions
- **Practice Lab** that generates new problems with step-by-step answers (Chapter 2 has a Venn Diagram Lab and a Place Value Lab)

Use the bar under each page title to move between chapters, and the **Previous / Next** buttons at the bottom of each section to move through a chapter in order.

## Final exam review

**[MTH 211 Final Exam Review](https://mrtkl.github.io/MTH-211/MTH211-Final-Exam-Review.html)**: a comprehensive practice final for Chapters 1–5 with detailed solutions, a final quiz for each chapter, and a practice lab with new problems from every chapter.

## Tools

**[Worksheet Graph Maker](https://mrtkl.github.io/MTH-211/Worksheet-Cartesian-Graph-Maker.html)**: build printable coordinate graphs and number lines for worksheets and exams, and export them as PNG or SVG.

## For instructors

- The pages are self-contained HTML files. To use them offline or in Canvas, download a file and open it in a browser, or link to the page URL.
- Pages support light and dark mode and work on tablets and phones.
- Links to a specific section work directly, for example [`Chapter1-Introduction to Problem Solving.html#a12`](https://mrtkl.github.io/MTH-211/Chapter1-Introduction%20to%20Problem%20Solving.html#a12) opens Activity 1.2.

Chapter 2 Notes (1): Introduction to Sets

Read pp. 42–51

The ideas about sets in this section are central to how children form the concept of number. Before a child can say “there are five,” they must see a collection as one thing and compare it with other collections.

Set. A set is a collection of objects called elements (or members). A set must be well defined: for any object, we can decide whether it is in the set or not.

We write a ∈ A for “a is an element of A” and a ∉ A for “a is not an element of A.” Sets are usually named with capital letters; elements can be anything at all: numbers, letters, people, even other sets.

Example. S = {Sancho, Jill, Ron} is a perfectly good set. So is T = {♠, ♥, ♦, ♣}, and so is W = {∅, {1}, {1, 2}}, whose elements are sets.

1. Three ways to describe a set

  • Verbal description: “the set of the first five letters of the English alphabet.”
  • Listing (roster): {a, b, c, d, e}. An ellipsis “…” continues a clear pattern: {1, 2, 3, …, 100} or {0, 2, 4, …}.
  • Set-builder notation: {x | x is a letter among the first five of the alphabet}, read “the set of all x such that …”.

2. Finite and infinite sets

A set is finite if it is empty or its elements can be counted, with the count ending. Otherwise it is infinite. For a finite set A, n(A) is the number of elements of A (its cardinal number).

The empty set (or null set) has no elements. It is written ∅ or { }, and n(∅) = 0. Careful: {0} and {∅} are not empty; each has one element.

3. Relationships between sets: equal and equivalent

Equal sets. Two sets A and B are equal, written A = B, if they have exactly the same elements. Order and repetition do not matter: {1, 2, 3} = {3, 1, 2} = {1, 1, 2, 3}.

How do these sets compare? E = the even whole numbers and D = the whole numbers divisible by 2. Every even number is divisible by 2 and every number divisible by 2 is even, so E = D: two different descriptions of one set.

Now compare E = {0, 2, 4, 6, …} with O = {1, 3, 5, 7, …}, the odd whole numbers. They share no elements, so they are not equal. But we can pair them perfectly: 0↔1, 2↔3, 4↔5, …, n↔n + 1. This is a one-to-one correspondence: every element of each set is paired with exactly one element of the other.

Equivalent sets. A and B are equivalent, written A ~ B, if there is a one-to-one correspondence between them. For finite sets, A ~ B exactly when n(A) = n(B).
  • Are equal sets always equivalent? Yes. Match each element with itself.
  • Are equivalent sets always equal? No. {a, b, c} ~ {1, 2, 3}, but the sets have different elements.

4. Subsets and proper subsets

Subset. A is a subset of B, written A ⊆ B, if every element of A is also an element of B. Formally: A ⊆ B means “if x ∈ A, then x ∈ B.”
Proper subset. A is a proper subset of B, written A ⊂ B, if A ⊆ B and B has at least one element that is not in A (so A ≠ B).
  • Every set is a subset of itself: A ⊆ A, but A is never a proper subset of itself.
  • The empty set is a subset of every set: there is no element of ∅ that could fail to be in B.
  • A set with n elements has 2n subsets: each element is either in or out. Exactly one of these (the set itself) is not proper, so there are 2n − 1 proper subsets.
  • Do not mix up ∈ and ⊆: 2 ∈ {1, 2} but {2} ⊆ {1, 2}.

3. Set “arithmetic” (operations on sets)

Union. A ∪ B = {x | x ∈ A or x ∈ B}, the elements in at least one of the sets (“or” includes “both”).
Intersection. A ∩ B = {x | x ∈ A and x ∈ B}, the elements in both sets. If A ∩ B = ∅, the sets are disjoint.
Set difference. A − B = {x | x ∈ A and x ∉ B}, the elements of A that are not in B. Note A − B = A ∩ B.
Complement. A = {x | x ∈ U and x ∉ A}, everything in U that is not in A. Some books write A′.
Cartesian product. A × B = {(a, b) | a ∈ A and b ∈ B}, the set of all ordered pairs whose first entry comes from A and second from B. For finite sets, n(A × B) = n(A) · n(B). This is the set model behind multiplication (Chapter 3).

4. Order of operations

Work inside parentheses first. A bar over a whole expression acts like parentheses: find the set under the bar, then take its complement. A bar over a single letter is done first.

Example: compare A ∩ B with A ∩ B. In the first, take each complement, then intersect: only the region outside both circles. In the second, intersect first (the lens), then take the complement: everything except the lens. They are different sets.

Shading both sides of a statement also verifies the properties of the operations: commutative, associative, distributive, and De Morgan’s laws (A ∪ B = A ∩ B and A ∩ B = A ∪ B). If the same regions are shaded, the two sets are equal for every choice of sets.

5. Counting with Venn diagrams

If we add n(A) and n(B), the elements of A ∩ B are counted twice, so

n(A ∪ B) = n(A) + n(B) − n(A ∩ B).

Chapter 2 Notes (3): Whole Numbers & Numeration

Read pp. 57–64Leads to Activity 2.7

1. Important definitions

Number. An idea: the property shared by all sets that are equivalent to one another. “Three” is what {a, b, c}, {♠, ♥, ♦} and {Jill, Ron, Cory} have in common.
Numeral. A symbol or name used to represent a number: 3, three, III and ||| are all numerals for the same number.
  • Cardinal numbers tell how many: “There are 24 students.”
  • Ordinal numbers tell position in an order: “She finished 3rd.”
  • Identification numbers name or label something; they do not count or order: a phone number, a jersey number, a ZIP code.

2. Chronology of a child’s learning the concept of number

  1. Counting chant. The child recites “one, two, three, …” as a memorized sequence of words, often without connecting it to objects.
  2. Matches counting-chant words with objects. The child points to one object for each word, a one-to-one correspondence between words and objects. The last word said tells how many.
  3. Observes the attribute common to all equivalent sets. The child realizes that every set that can be matched with {one, two, three} has the same “threeness,” whatever its objects are.

3. Formal definition of n(A)

Definition. The number of elements in a nonempty finite set A, written n(A), is m when A ~ {1, 2, 3, …, m}. Also, n(∅) = 0.
Example. If S = {@, &, #}, then n(S) = 3 because S ~ {1, 2, 3}: @ ↔ 1, & ↔ 2, # ↔ 3.

4. Ordering whole numbers

There are three methods for ordering whole numbers:

  1. Counting chant: a < b if a is said before b in the counting chant.
  2. Matching elements of sets: pair the elements of a set with a elements and a set with b elements one to one; if elements of the second set are left over, a < b.
  3. Number line: a < b if a is to the left of b on the number line.
Formal definition. Let a = n(A) and b = n(B). Then a < b (a is less than b), or b > a (b is greater than a), if A is equivalent to a proper subset of B. This is exactly what method 2 does.

1. Several numeration systems

The text explores several numeration systems before discussing our Hindu–Arabic system: tally, Egyptian, Roman, Babylonian and Mayan. We are mainly interested in their important features, and focus on Roman numerals versus Hindu–Arabic numerals. Type a number to see it written in every system.

2. Roman numeration

Roman numeral symbols and values

  • Additive: symbols are added when they appear from largest to smallest: CLX = 100 + 50 + 10 = 160.
  • Subtractive: a smaller symbol before a larger one is subtracted. Only I before V or X, X before L or C, and C before D or M: IV = 4, XC = 90, CM = 900.
  • Multiplicative: a bar over a numeral multiplies it by 1000: V = 5000.
  • There is no symbol for zero and no place value: the X in XV and in XC means 10 either way.

3. Attributes of numeration systems

  • Additive: the value of a numeral is the sum of the values of its symbols.
  • Subtractive: the position of a symbol can mean subtraction (IV = 5 − 1).
  • Multiplicative: a symbol’s value is multiplied by something, such as a digit times its place value (3 in 300 means 3 × 100) or the Roman bar (× 1000).
  • Positional: the position of a symbol affects its meaning.
  • Place value: each position has a value that is a power of the base (or close to it), and a digit’s value is the digit times its place value.
  • Placeholder: a symbol (our 0) that holds an empty place, so 305 and 35 look different.

4. The Hindu–Arabic system and expanded form

The Hindu–Arabic numeration system (our system) is a base ten place-value system with ten digits, 0 through 9. Its attributes become very clear in expanded form: write the numeral as the sum of each of its digits multiplied by its place value.

Example. 3,405 = 3 × 1000 + 4 × 100 + 0 × 10 + 5 × 1 = 3 × 103 + 4 × 102 + 0 × 101 + 5 × 100. Each product shows multiplicative, the sum shows additive, the powers of ten show place value, and the 0 is the placeholder.

Activity 2.7: Using Alternate Bases to Explore Place Value

Notes Notes (3)Manipulative base three and base five pieces

Base three pieces, from smallest to largest, are units, longs, flats and blocks. Put yourself in the mindset of a child who does not yet know about place value or base ten: do not count the piles in base ten. Group and exchange instead.

1. The base three pieces

a. What relationship do you observe between the different size pieces? How could you use units to create a long? Longs to create a flat? Flats to create a block?

b. What would the next larger piece after a block look like? Sketch it and describe how it was created.

Show an answer

Three units make a long, three longs make a flat, three flats make a block. Each piece is made of three of the previous one. The next piece is three blocks joined in a row: a “long of blocks.”

2. Group and exchange a pile of units (base three)

a. Group units into longs. b. Keep grouping and exchanging until the pile uses the fewest base three pieces. c. Record the result in the table.

3. Another pile (base three)

a. Repeat the process: go from one size piece to the next, one at a time. b. Make a table.

4. Which digits are allowed?

When working in base three, after all possible groupings and exchanges, what digits can appear in the final table? Why?

Show an answer

Only 0, 1 and 2. Whenever there are three of a piece, they are exchanged for one of the next larger piece, so at most two of any piece can remain.

Each piece is one place value. For any base other than ten, write the base as a word: 1201three.

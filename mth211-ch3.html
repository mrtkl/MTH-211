Chapter 3 overview

Textbook Musser et al. 10e, Ch. 3Sections 3.1 Addition and Subtraction · 3.2 Multiplication and Division · 3.3 Ordering and Exponents

Big idea. Each operation is defined from what we already know: addition from the union of disjoint sets, subtraction from addition (missing addend), multiplication from addition (repeated addition), and division from multiplication (missing factor). For each operation, future teachers need three things: the conceptual approaches children use, the models (set and measurement) that show them, and the properties that make the basic facts and mental math work.

Approach vs. model. An approach is the way of thinking about the operation (take-away, missing addend, sharing, …). A model is the picture used to show it (a set of objects or a number line). Every problem is solved with one of each.

How to use this file. The notes pages explain the content with manipulatives you can project. Each activity page lists the handout’s questions in order with buttons that open the matching tool, already set up.

Chapter 3 Notes (1): Addition of Whole Numbers

Read pp. 84–96Leads to Activity 3.2

1. Set model for addition

Definition. Let a and b be whole numbers. If A and B are disjoint sets with n(A) = a and n(B) = b, then the sum of a and b is a + b = n(A ∪ B).
Example. A = {♠, ♥, ♦} and B = {★, ●}. These sets are disjoint and A ∪ B = {♠, ♥, ♦, ★, ●}, so 3 + 2 = n(A ∪ B) = 5.

In the equation a + b = c, a and b are the addends and c is the sum.

Why disjoint? If the sets share elements, the union counts each shared element only once, so n(A ∪ B) would be less than a + b. Try it below.

2. Measurement model for addition

On the whole-number line, a is an arrow of length a starting at 0, and b is an arrow of length b placed at the end of the first. The sum is where the second arrow ends. To model 3 + 5: an arrow from 0 to 3, then an arrow of length 5 from 3 to 8.

Notice that the arrows are placed end to end and do not overlap, just as the sets in the set model are disjoint.

3. Properties of addition

  • Closure: the sum of any two whole numbers is a whole number. We say “the set of whole numbers is closed under addition.”
  • Commutative: for all whole numbers a and b, a + b = b + a.
  • Associative: for all whole numbers a, b and c, (a + b) + c = a + (b + c).
  • Identity: there is a unique whole number, 0, such that a + 0 = 0 + a = a for every whole number a. Zero is the additive identity: adding it preserves the identity of the number.

Use the number line above: choose a property to see why it is true for every choice of numbers, not just one example.

Chapter 3 Notes (2): Subtraction of Whole Numbers

Read pp. 84–96Leads to Activity 3.3

In the subtraction equation a − b = c, a is the minuend, b is the subtrahend, and c is the difference.

1. The take-away approach

Definition (set model). Let a and b be whole numbers and A and B be sets with n(A) = a, n(B) = b and B ⊆ A. Then a − b = n(A − B).
  • Set model example: Jill has 9 marbles and gives away 5. Show 9 counters, remove 5, and 4 remain: 9 − 5 = 4.
  • Measurement model example: on the number line, draw an arrow from 0 to 9, then an arrow of length 5 pointing back from 9. It ends at 4.

2. The missing-addend approach

Definition. Let a and b be whole numbers. Then a − b = c if and only if a = b + c for some whole number c. c is called the missing addend.

The missing-addend definition shows the relationship between addition and subtraction: every subtraction is an addition with one addend unknown.

  • Set model example: Ron has 5 stickers and needs 9 for a page. How many more? Start with 5 counters and add counters until there are 9: he adds 4, so 5 + 4 = 9 and 9 − 5 = 4.
  • Measurement model example: draw an arrow from 0 to 5; how long an arrow reaches 9? Jump from 5 to 9: the jump has length 4.

3. Four-fact families

Because of the commutative property and the missing-addend relationship, 5 + 4 = 9 belongs to a family of four facts: 5 + 4 = 9, 4 + 5 = 9, 9 − 4 = 5 and 9 − 5 = 4.

4. The comparison approach

In some problems another step must come first. Cory has 9 cards and Hasni has 5. How many more cards does Cory have? We first match the two sets one to one (comparison), then find how many are left over, either by taking away the matched ones or by asking what must be added to 5 to get 9.

This is the comparison approach together with the take-away or missing-addend approach. The comparison approach is not enough alone; it is always followed by one of the other approaches.

Approach vs. model. When solving a problem, you choose both an approach (take-away, missing addend, comparison) and a model (set or measurement) that illustrates that approach.

Chapter 3 Notes (3): Multiplication of Whole Numbers

Read pp. 101–111Leads to Activity 3.4

In the equation a × b = c, a and b are the factors and c is the product.

Three approaches to multiplication

1. Repeated addition. Let a and b be whole numbers. Then a × b = b + b + … + b (b added to itself a times). This depends on the relationship between addition and multiplication. (Also, 1 × b = b and 0 × b = 0.)
  • Set model example: 3 bags with 4 apples in each: 4 + 4 + 4 = 3 × 4 = 12.
  • Measurement model example: 3 jumps of length 4 on the number line, end to end, land on 12.
2. Rectangular array. Let a and b be whole numbers. Then a × b is the number of objects in an array with a rows and b columns (an a by b rectangle).
3. Cartesian product. Recall that S × T is the set of all ordered pairs (s, t) with s ∈ S and t ∈ T. If n(A) = a and n(B) = b, then a × b = n(A × B).
Example. 3 shirts and 2 pairs of pants make 3 × 2 = 6 outfits, one for each ordered pair (shirt, pants). A tree diagram lists them.

Explore the models

See the same product as repeated addition, an array and a Cartesian product, with a set or a measurement model.

Properties of multiplication

  1. Closure: the set of whole numbers is closed under multiplication, since the product of any two whole numbers is a whole number.
  2. Commutative: for any whole numbers a and b, a × b = b × a.
  3. Associative: for any whole numbers a, b and c, (a × b) × c = a × (b × c).
  4. Identity: the number 1 is the multiplicative identity since, for any whole number a, a × 1 = 1 × a = a.
  5. Distributive property of multiplication over addition (subtraction): for any whole numbers a, b and c, a × (b + c) = a × b + a × c and a × (b − c) = a × b − a × c (when b ≥ c).
  6. Multiplication property of zero: for every whole number a, a × 0 = 0 × a = 0.

Chapter 3 Notes (4): Whole-Number Division

Read pp. 101–111Leads to Activity 3.5

In the expression a ÷ b = c, a is the dividend, b is the divisor, and c is the quotient. Division of whole numbers can be interpreted conceptually in two different ways:

1. Sharing (partitive) division. There are r objects to be divided (shared, or partitioned) into s groups. The answer to r ÷ s is the number of objects in each group.
2. Measurement (subtractive, grouping) division. There are r objects to be divided (measured out) into groups with s objects each. The answer is the number of groups you form.

Other notation: a ÷ b can also be written a/b, as a fraction with a over b, or with the long-division bracket, b written outside and a inside.

Division related to the other operations

1. Missing-factor approach (relates division to multiplication). If a and b are whole numbers and b ≠ 0, then a ÷ b = c if and only if c is the whole number with b × c = a.
Example. To model 28 ÷ 7, use 28 units to form a rectangle with one side of length 7. The answer is the missing side of the rectangle: the number that, when multiplied by 7, makes 28. It is 4.
2. Repeated-subtraction approach (relates division to subtraction). a ÷ b is the number of times b can be subtracted from a until 0 is reached.
Example. 15 ÷ 5: 15 − 5 = 10, 10 − 5 = 5, 5 − 5 = 0. We subtracted 5 three times, so 15 ÷ 5 = 3.

Explore the approaches

Division involving 0, and the division algorithm

  • If a is any nonzero number, then 0 ÷ a = 0, because a × 0 = 0.
  • a ÷ 0 is undefined for all whole numbers a. If a ≠ 0, no c makes 0 × c = a. If a = 0, every c makes 0 × c = 0, so there is no unique answer.
The division algorithm. If a and b are whole numbers and b ≠ 0, then there exist unique whole numbers q (quotient) and r (remainder) such that a = bq + r with 0 ≤ r < b.

Examples: 23 = 5 · 4 + 3, so 23 ÷ 5 has q = 4 and r = 3. And 4 = 5 · 0 + 4, so 4 ÷ 5 has q = 0 and r = 4.

Chapter 3 Notes (5): Ordering Whole Numbers

Read pp. 116–121Leads to Activity 3.7

We have already seen three methods for ordering whole numbers: the counting chant, matching elements of sets (the set method), and the number line. Now that we have whole-number operations, there is a new formal definition:

Definition (less than for whole numbers). a is less than b, written a < b, if and only if there is a nonzero whole number n such that a + n = b.

Examples: 3 < 8 because 3 + 5 = 8. And 0 < 4 because 0 + 4 = 4. But 6 is not less than 6: the only n with 6 + n = 6 is n = 0, which is not allowed.

See the definition on a number line

Properties of less than and whole-number operations

  1. Transitive: for all whole numbers a, b and c, if a < b and b < c, then a < c. Example: 2 < 5 and 5 < 9, so 2 < 9. (2 + 3 = 5 and 5 + 4 = 9, so 2 + 7 = 9.)
  2. Less than and addition: if a < b, then a + c < b + c. Example: 3 < 7, so 3 + 10 < 7 + 10, that is, 13 < 17.
  3. Less than and multiplication: if a < b and c ≠ 0, then a × c < b × c. Example: 3 < 7, so 3 × 4 < 7 × 4, that is, 12 < 28. (With c = 0 both products are 0, so the inequality fails.)

Activity 3.7: Exploring the Closure Property

Notes Notes (1), (3), (5)Manipulative closure tester
Closure. A set A is closed under addition if whenever a ∈ A and b ∈ A, we know that a + b ∈ A. Likewise A is closed under multiplication (a × b ∈ A), subtraction (a − b ∈ A) or division (a ÷ b ∈ A) when the result is always in A. Note: a and b may be the same number.
  • Not closed: one counterexample is enough. “This set is not closed under addition because 1 and 2 are in the set and 1 + 2 = 3, but 3 is not in the set.”
  • Closed, infinite set: give a general argument: write two elements in general form (for example 2m and 2n), apply the operation, and show the result has the same form.
  • Closed, finite set: list every result and check that each one is in the set.

The tester below searches for a counterexample among small elements and shows the general argument when the set is closed. Decide first, then test.
